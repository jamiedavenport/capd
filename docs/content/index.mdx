## Save anything. Find it in seconds.

Capd is a private, native macOS app for capturing useful web pages, selected
text, links, notes, and images—then finding them again with full-text search.

No account. No subscription. No telemetry. Your library stays on your Mac.

[Download the latest release](https://github.com/jamiedavenport/capd/releases/latest)
· [Install with Homebrew](/install#homebrew)

![Capture a page, then find it again with full-text search](/capture-to-search.gif)

## Capture without breaking focus

Press **⌃⌥C** in any app, drag a link or image to the menu bar or MacBook notch,
or share a page through the macOS share sheet. A compact HUD confirms what was
saved and lets you add a note without opening a main window.

Capd understands links, selected text, clipboard images, and dropped files. It
also removes common tracking parameters and folds repeat captures into the
existing item.

[See every way to capture](/capture)

## Search what you remember

Press **⌥⇧Space** for fast, keyboard-first search across titles, websites,
notes, selections, readable page content, and text recognized inside images.
On-device tags provide another quick way to narrow a growing library.

## Private by design

Everything Capd stores lives in a SQLite database and assets folder on your
Mac. There is no cloud account, sync service, analytics, or telemetry. OCR and
automatic tagging run on-device.

[Read the privacy details](/privacy)

## Powerful when you need it

The bundled `capd` CLI captures, searches, and exports the same local library.
It offers stable JSON output for automation and a read-only MCP server for
compatible AI assistants.

[Explore the CLI](/cli)

## Get started

1. [Download and install Capd](/install).
2. Press **⌃⌥C** anywhere to save your first capture.
3. Press **⌥⇧Space** and search for a word from it.
