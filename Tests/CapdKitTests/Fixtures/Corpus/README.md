# Golden corpus

Real pages fetched from the live web on 2026-08-02 with a Safari user agent, committed so
extraction and search tests run offline. `manifest.json` records, per fixture, the source
URL, the capture title, phrases the page's visible text contains, the body status
extraction lands the page on, and a query that identifies the fixture uniquely across the
corpus. The two PNG fixtures are rendered screenshots whose text the OCR step reads back.
